# PR 14 · Motion

Web renders (react-native-web, mock backend, sensor simulator) of the new motion. The web preview runs animations on the JS driver, so frame timing is only indicative; real 60 fps is a device check.

- `motion-flow.mp4`: Today ring fill, level lock, 3-2-1 sweep and digit roll, live count roll, summary badge fade, Today ring fill + count roll after a set, phone-moved.
- `motion-flow-reduce-motion.mp4`: the same run with Reduce Motion on (crossfades, no moves).
- `flow-frames.png`, `flow-frames-reduce-motion.png`: the same runs as frame sequences, 2 frames per second, left to right, top to bottom.
- `today-ring-fill-frames.png`, `level-lock-frames.png`, `countdown-sweep-frames.png`, `count-roll-frames.png`, `badge-fade-frames.png`: close-ups, 10 to 20 frames per second.
